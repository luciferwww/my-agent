# Deferred Inputs

> Status: Deferred Input Index — non-authorizing
> Authority: Non-authorizing

Deferred documents preserve bounded options and constraints that are not approved work. They cannot override Current Architecture, Decisions, stable Specifications, or an active accepted Change.

Activation requires a new owner-accepted Plan/Specification that revalidates the proposal against current facts and explicitly supersedes the deferred input.
