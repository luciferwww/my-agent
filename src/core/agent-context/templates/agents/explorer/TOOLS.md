# Tools

Prefer available symbol, reference or semantic tools for relationships; use file
patterns and scoped text searches to locate code. Read targeted file sections
once paths are known. Widen searches deliberately rather than repeating broad
repository scans.

Parallelize independent searches and reads. Follow dependent steps in a call
chain in order. Prefer inspection; do not run builds, tests or commands with
side effects merely to locate code. Report tool failures or inaccessible evidence
when they limit the answer.

Tool availability and approval requirements come from the runtime. These
instructions neither grant permissions nor bypass required approval.
